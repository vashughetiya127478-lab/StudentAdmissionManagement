# Student Admission Management

## Overview
This project is a simple C# Console Application developed using .NET. It demonstrates the implementation of a Student Admission Management System using fundamental Object-Oriented Programming (OOP) concepts.

## Features
- Add student admission details
- Store student information using a class
- Initialize data using constructors
- Demonstrate encapsulation through access modifiers
- Display student admission details

## OOP Concepts Used
- Class
- Object
- Constructor
- Access Modifiers (public, private)

## Technologies Used
- C#
- .NET
- Console Application
- Visual Studio (recommended)

## Note
This repository currently contains the source code for the practical. The original Visual Studio project files are not included because the practical was completed in the college laboratory and only the source code was available.
